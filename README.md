# Solo Switch (다인봇 ↔ 1인봇)

다인봇(캐릭터 카드 1장에 여러 캐릭터가 있는 봇)으로 플레이하다가, 그중 한 캐릭터와 **대화 기록을 그대로 이어서** 1:1로 이야기하고, 다시 다인봇으로 돌아올 수 있게 해 주는 SillyTavern 확장입니다.

UI 언어: 한국어 / English / 日本語 / 中文 (실리태번 언어를 자동으로 따르고, 설정에서 직접 고를 수도 있어요)

## 두 가지 전환 방식

| 방식 | 하는 일 | 돌아갈 때 고를 수 있는 것 |
|---|---|---|
| **A 1인봇 카드로 옮기기** | 내가 가진 A 1인봇 카드에 새 채팅을 만들어서, 지금까지의 다인봇 대화를 복사한 뒤 그 채팅을 열어요. 원본 다인봇 채팅은 건드리지 않아요. | ① 다인봇 채팅에 이어 붙이기 (1:1에서 새로 나눈 메시지만 뒤에 붙음) ② 따로 보관 (다인봇 채팅은 그대로) |
| **카드는 그대로, 한 캐릭터만 말하게** | 같은 다인봇 채팅에서 "이제 A만 등장한다"는 지시를 AI에게 넣어요. 캐릭터 메모(말투·관계 등)도 덧붙일 수 있어요. | ① 이 채팅에 그대로 남기기 ② 1:1 부분은 새 채팅 파일로 보관하고, 지금 채팅은 1:1 시작 전으로 되돌리기 |

- 시작할 때도 돌아갈 때도 팝업에서 매번 고릅니다.
- 1:1 모드일 때는 입력창 위에 `1:1 · A [돌아가기]` 표시가 떠요.
- 같은 1:1 채팅에서 "이어 붙이기"를 두 번 해도 메시지가 중복되지 않아요.
- 옮긴 메시지는 원래 프로필 사진을 유지해요 (다인봇 메시지는 다인봇 사진, 1:1 메시지는 1인봇 사진). 설정에서 끌 수 있어요.
- 다인봇 카드 이름을 바꿨다면, 돌아갈 때 바뀐 카드를 직접 고를 수 있어요.

## 설치

1. 실리태번 → 확장(블록 아이콘) → **Install extension**에 이 저장소의 GitHub 주소를 넣거나,
2. 이 폴더(`SillyTavern-SoloSwitch`)를 통째로 `SillyTavern/data/<사용자 이름>/extensions/` 안에 넣고 실리태번을 새로고침하세요.

## 사용법

- 입력창 왼쪽 **마법봉 메뉴 → "1:1 대화로 전환"** (1:1 모드일 때는 "다인봇으로 돌아가기"로 바뀜)
- 또는 확장 설정의 **솔로 스위치** 패널 버튼
- 슬래시 커맨드: `/solo` (전환 창 열기), `/solo 아린` (바로 아린 한 캐릭터 모드), `/solo-back` (돌아가기 창)

## 설정

- UI 언어 (자동 / 한국어 / English / 日本語 / 中文)
- 채팅 데이터도 같이 옮기기 (채팅 변수, 작가 노트, 다른 확장의 채팅별 기록) — 기본 켜짐
- 옮긴 메시지에 원래 프로필 사진 유지 — 기본 켜짐
- 1인봇 카드로 옮겼을 때 "이전 기록은 다인봇 이야기"라는 안내를 AI에게 넣기 — 기본 켜짐
- 입력창 위 상태 표시 — 기본 켜짐
- 지시문 삽입 깊이 — 기본 1
- AI가 읽는 지시문 2개 직접 수정 가능 (영어 권장). `{{focus}}` = 캐릭터 이름, `{{note}}` = 메모

AI가 읽는 지시문은 영어로 되어 있지만 "지금까지 쓰던 언어로 계속 쓰라"는 내용이 들어 있어서, 한국어·중국어·일본어·영어 롤플 모두 원래 언어로 이어집니다.

## 다른 확장과 함께 쓰기

Blue Lemonade, 코끼리를 생각하지마, 레모나 도우미, 전개지시M(Direction-Manager-DB), Direction-Manager-Lite, Background Reply(백그라운드 답장)와 함께 쓰도록 확인했어요.

- 이름이 겹치는 곳이 없어요 (설정 키, 채팅 기록 키, 화면 요소 id, 슬래시 커맨드, 지시문 키 모두 따로).
- AI 지시문은 실제 답변에만 들어가요. 다른 확장이 뒤에서 돌리는 요약·번역·분석 요청과 사칭(impersonate)에는 들어가지 않아요.
- 채팅을 옮길 때 다른 확장의 채팅별 기록(코끼리 기억장, 레모나 캐해 등)도 같이 복사돼요. 레모나 캐해는 카드별로 저장되기 때문에 1인봇 카드에 다인봇 캐해가 섞이지 않아요.
- "1:1 부분만 따로 보관"으로 메시지를 지울 때는 실리태번이 메시지를 지울 때와 같은 신호를 보내서, 기억/추적 확장이 따라올 수 있어요.
- Background Reply: 백그라운드 답장이 아직 지금 채팅에 들어오는 중이면 전환을 잠깐 막아요 (답장이 엉뚱한 채팅에 남지 않게). 답장이 들어온 뒤 누르면 돼요.
- Blue Lemonade를 켜 두면 이 확장의 창과 상태 표시도 Blue Lemonade 색을 따라가요.

## 알아두기

- 실리태번 **그룹 채팅**은 지원하지 않아요 (캐릭터 카드 1장짜리 다인봇 전용).
- "이어 붙이기"는 1:1 대화 중 새로 생긴 메시지만 원본 뒤에 붙여요. 1:1 중에 예전 메시지를 고쳤다면 그 수정은 원본에 반영되지 않아요.
- 1:1 채팅의 AI 메시지는 그 카드 이름(예: A)으로 저장되기 때문에, 다인봇 채팅에 이어 붙이면 그 부분은 A 이름으로 보여요. 단, 나중에 다인봇 카드 이름을 바꾸면 실리태번이 그 카드의 모든 채팅에서 AI 메시지 이름을 새 이름으로 바꿔요 (실리태번 기본 동작).
- AI가 답변하는 중에는 전환하지 않아요. 답변이 끝난 뒤 눌러 주세요.
- "되돌리기"를 고르면 1:1 메시지는 지우기 전에 새 채팅 파일로 먼저 저장돼요. 채팅 목록에서 `카드이름 - 1on1 A - 날짜` 이름으로 찾을 수 있어요.
- 이 확장은 실리태번 서버 안에서만 채팅 파일을 읽고 저장해요. 외부로 보내는 데이터는 없어요.
